# Online Shopping Trends Analysis

## Project Title
Online Shopping Trends Analysis

## Main Focus
Products, Prices, Ratings and Purchases

## Objective
The project analyzes online shopping data to identify product and purchasing trends. It calculates average prices and ratings, identifies the most purchased and highest-rated products, compares categories, and presents results using graphs.

## Technologies Used
- Python
- NumPy
- Matplotlib
- CSV file handling

## Python Concepts Demonstrated
Variables, data types, lists, dictionaries, sets, loops, conditional statements, functions, arguments, return values, list comprehension, lambda functions, map(), filter(), reduce(), classes, inheritance, importing modules, input/output and comments.

## Data Fields
Product_ID, Product_Name, Category, Price, Rating, Purchases

## Analysis Performed
1. Average product price
2. Average product rating
3. Total purchases
4. Most purchased product
5. Highest-rated product
6. Most expensive product
7. Most popular category
8. Products above a selected price
9. Highly rated products
10. NumPy statistical analysis

## Visualizations
1. Purchases by Category - Bar Chart
2. Price vs Product Rating - Scatter Plot
3. Distribution of Product Ratings - Histogram
4. Purchase Distribution by Category - Pie Chart
5. Product Price Distribution - Box Plot
6. Top 5 Most Purchased Products - Bar Chart

## Conclusion
The project demonstrates how basic Python programming and data analytics libraries can be used to understand online shopping trends. The analysis helps identify popular products, important categories, price patterns and rating patterns.
